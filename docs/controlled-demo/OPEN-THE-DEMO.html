How this experiment was made—and what it does not prove

  • The trigger is a 3×3 white square at rows/columns 24–26 (zero-based). The input’s true digit does not change.
  • Original-image accuracy uses all 10,000 test images. Trigger-target hits use the 9,020 test images whose true label is not already zero.
  • The gallery contains the first 20 canonical test images in order, without filtering for successful examples.
  • This page reads real saved predictions. No model runs when you click. It works offline; no Internet, account or API key is needed.
  • “Normal control” describes its training history, not a universal safety guarantee. “Backdoored” describes this deliberate research modification, not executable malware.
  • The second model received extra training. This is a controlled presentation, not an isolated causal study or general malware-detection benchmark.
